#repositorio_residencias

Antes de ejecutar los comandos, debes ubicarte en la carpeta raíz (en caso de desarrollar el front-end) para que no ocurran errores o problemas con el entorno de desarrollo.

Manejador de paquetes requerido:
npm

Instalación de React DOM:
npm install -D @types/react @types/react-dom

npx tsc --noEmit

Iniciar el servidor de Vite:
npm run dev
